# Controversies that forced rule changes

**Athens, 2004, men's all-around.** Yang Tae-young's parallel bars routine was
assigned a start value one tenth too low. He finished third; Paul Hamm won by
0.049. The federation acknowledged the error, suspended the three judges
responsible, and declined to alter the result. Two years later the Code of
Points was rewritten so that difficulty is an arithmetic sum of the elements
performed, produced by a panel that does nothing else and can be checked.

Whether Athens caused that rewrite is genuinely contested. The FIG's stated case
was that the 10.0 ceiling had become unusable: as difficulty climbed, too many
routines started from 10.0 and only execution could separate them, so the code
could no longer reward a harder routine. That argument predates Athens by years.
Both readings are in the entry, and neither is presented as settled.

**Sydney, 2000, the vault.** The apparatus was set five centimetres too low for
an entire rotation of the women's competition. The error is what people
remember; the review's finding is what changed the sport. The horse had almost
no tolerance for a hand placed slightly wrong, and it was replaced.

**Montreal, 1976.** Not a controversy and not a rule change, but the reason the
2006 entry costs the sport something. Nadia Comăneci scored 10.0 on the uneven
bars and the scoreboard, which had been built on the assumption that no one ever
would, displayed 1.00. For thirty years afterwards the perfect 10 was one of the
few numbers in sport that needed no explanation to anyone. It does not convert
into the current scale. It has no equivalent. It is simply gone, and that
absence is what the empty chart on this page is recording.
