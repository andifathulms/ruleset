# One number and no table

A panel of judges watches a <Term id="run">run</Term> and gives it one score
out of 100. The highest and lowest marks are dropped. The same is done for
each single trick.

The rules say what the judges should weigh: difficulty, execution, variety,
<Term id="flow">flow</Term>, use of the course and consistency. They do not
say how much each one counts, and no trick has a set value. The result is an
<Term id="impression-score">impression score</Term>.

<Photo id="skateboarding-worlds-2023-air" />

Other judged sports work differently. [Gymnastics](/sports/gymnastics/)
publishes a value for every element. [Diving](/sports/diving/) has a table of
degrees of difficulty. In those sports an athlete can add up what a routine is
worth before performing it, and a disputed score can be checked against a
document.

Skateboarding [chose to write no such
table](#worldskate-holistic-judging). Skaters hold that a trick has no fixed
value, because its difficulty depends on where and how it is done. A
<Term id="kickflip">kickflip</Term> down twelve stairs and a kickflip on flat
ground are different feats. A table that told them apart would have to list
every trick on every obstacle.

<Photo id="skateboarding-worlds-2023-stairs" />

So the judges are skaters, and the system rests on what skaters together know
to be hard. Contests were judged that way before there was a federation.

The method has a price. A score cannot be explained part by part. Panels are
hard to keep consistent with each other. A skater who thinks a score is wrong
has no document to point to.
