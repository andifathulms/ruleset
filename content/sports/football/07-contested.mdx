# What is still argued about

The Board amends the Laws every year, so football always has open arguments.
None of these is settled.

**Handball.** <Term id="handball">Handball</Term> is the most rewritten clause
in the book. The test has moved between intent, the position of the arm,
whether the arm made the body unnaturally bigger, and whether the ball came
off the player's own body first. Each version has swapped one kind of
unfairness for another. The law asks about a player's state of mind, and it is
enforced from a slow-motion camera that cannot see one.

**Offside and precision.** Tracking systems now judge
<Term id="offside">offside</Term> to the centimetre. Some want a tolerance
added. Others want an attacker to be offside only when there is clear space
between attacker and defender. Neither proposal has been adopted.

**Concussion substitutes.** Temporary substitutions for a suspected concussion
have been trialled, and player unions have pressed for them. The Board has
preferred permanent extra substitutions. The argument against the temporary
kind is that a team could misuse it.

**Stopping the clock.** Most sports stop the clock when play stops. Football
leaves <Term id="added-time">added time</Term> to one official's judgement.
Proposals to stop the clock return regularly.
