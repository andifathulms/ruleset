# What is still argued about

**Who speaks for the sport.** The Olympic movement recognises WAKO. Rival
international bodies still sanction world titles, and commercial promotions
run their own rules where most of the money is. Those bodies dispute that any
one federation speaks for kickboxing.

**Which discipline is kickboxing.** <Term id="full-contact">Full
contact</Term> bars leg kicks. Low kick allows them. K-1 style adds knees.
Point fighting stops after every point and is a different kind of contest
from the ring codes. The federation runs them all as separate disciplines, so
the sport has no single set of rules, and whether point fighting belongs
beside the others is argued from time to time.

**The minimum kick rule.** It works. It also raises a question: if fighters
must be made to kick, can the kick hold its own in a real contest? The
question comes back whenever the rule is enforced against a fighter who was
winning.

**Judging.** Continuous bouts are scored by eye, round by round, with the
difficulties [boxing](/sports/boxing/) has had. Boxing tried scoring by
button in 1992 and gave it up in 2016.
[Taekwondo](/sports/taekwondo/) fitted sensors, and the sport changed.
Kickboxing has done neither.

**Headguards.** The light codes keep them, and the ring codes vary. Boxing
removed them for elite men in 2013, on evidence that is itself disputed.
