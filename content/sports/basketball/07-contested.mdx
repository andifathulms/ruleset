# What is contested now

Recorded as unsettled.

**Whether the three-point line broke the game it saved.** The arc was added to
open the floor, and it did. Four decades later the argument is that it has done
so too well: teams shoot from range because the arithmetic says to, mid-range
shooting has largely disappeared, and the objection is that a rule intended to
add variety has produced a different monoculture. Proposals to move the line,
to add a four-point zone, or to vary the value by distance all circulate. None
has been adopted, and the sport is aware that any of them would sever its
statistics a second time.

**Two rulebooks.** FIBA and the NBA have converged on the shot clock and moved
closer on the arc without ever unifying. Whether a sport this global should
have a single set of rules is an argument nobody wins, because neither body can
compel the other and the professional league has no incentive to be governed.

**Load and the calendar.** Player workload, and the practice of resting
healthy players in professional fixtures, is a governance dispute with a
sporting cause. It has produced regulation about availability rather than about
play, which is an unusual shape for a rule.

**The height barrier.** Not a rule argument, and included because it is the
thing this sport's learning curve rests on. Nobody proposes raising the rim,
and the reason nobody proposes it is that a century of records would stop
meaning anything — which is exactly the trade every federation on this site has
had to weigh at least once.
