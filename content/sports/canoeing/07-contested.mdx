# What is still argued about

**Does kayak cross belong?** It puts a contact race inside a discipline built
on timed runs by one boat. It makes slalom easier to watch, and it is a
different kind of contest.
[Sport climbing](/sports/sport-climbing/) has the same argument about its
speed event.

**Is fifty seconds too much?** One missed gate ends a run. The question comes
up after every major final. The answer so far is that any softer, graded
penalty would bring back a judge's opinion of how bad the mistake was.

**Who pays for equality?** Women's canoe events arrived by removing men's
events, because the number of athletes is fixed. Few people defend that
method, and it will be used again whenever the programme is rebalanced.

**Who can afford whitewater?** Slalom depends more and more on built channels.
No rule requires them and no rule can make them cheaper.

**Two sports, one federation.** Sprint and slalom share a paddle and a quota
of athletes, and little else. Every decision about the programme sets one
against the other.
