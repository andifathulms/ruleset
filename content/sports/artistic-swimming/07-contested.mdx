# What is still argued about

**The base mark.** When an element does not match its declaration, it gets a
<Term id="base-mark">base mark</Term>, its minimum value. In an open letter in
2024 a world championship athlete called the system "disrespectful to the
athletes' work". The letter's example was a <Term id="hybrid">hybrid</Term> of twenty
movements: miss one, the letter argued, and the punishment is as heavy as for
missing all twenty.

**Execution against difficulty.** The same letter said that judges use too
little of the scale. Marks "mostly float between 6.75 and 8.5", it said, so
the declared difficulty decides the result. The open question is whether the
2023 system made the sport more objective or only more predictable.
