# What is still argued about

**Whether it is one sport.** Taolu is a judged performance and sanda is a
full-contact fight. They share a name and a federation. For any programme that
counts medal events and wants one clear entry, this is the main problem.
Nobody proposes separating them.

**Whether standard wushu represents Chinese martial arts.** The argument has
run since the 1950s. Some championships hold separate categories for
traditional styles. That has eased the argument and has not settled it.

**Declared difficulty.** Whether nandu produced a martial sport, or a
gymnastic one with weapons, is still disputed.

**One country's standard.** No other national programme compares with China's
specialist schools in taolu. It is hard to argue that a sport belongs to the
whole world from that position.

**The Olympic campaign.** The sport was staged at a Games without being in it,
and the federation called that progress. It still has no place. What the
campaign should look like now, and whether it should go on, are questions the
federation has not answered in public.

**The edge of the platform.** Sanda's defining rule is also its safety
question. A throw beside an 80-centimetre drop is more dangerous than the same
throw in the centre.
