# Controversies that forced rule changes

**Local knowledge.** The founding problem. A competitor who knew a forest could
beat a better navigator who did not, which made results a measure of residence.
The answer — embargo the area, publish nothing, hand over the map at the start
— is now so fundamental that it reads as the definition of the sport rather
than as a rule that had to be imposed.

**Following.** Individual starts at intervals exist so that competitors
navigate alone. A runner who catches another and simply follows them has
converted the event into a running race, and it is an offence against fair
play, judged from splits and, latterly, from GPS traces. The relay disciplines
solve it structurally instead, by giving teams different combinations of the
same controls.

**Terrain that suited one country.** World championships held repeatedly in
Nordic forest produced Nordic winners, and the rotation of terrain types is now
deliberate. It is a fairness rule aimed at the sport's own geographic
concentration.

**Mispunching.** Under paper cards, a competitor could be disqualified for a
punch mark that was present but illegible, with no way to prove otherwise.
Electronic punching in the 1990s removed the class of dispute entirely — one of
the cleanest technology-solves-a-rule-problem cases on this site.

**GPS.** Banned for navigation and required for broadcast, which is a fine line
that has to be policed: the device a competitor carries for the audience must
not be readable by the competitor. The sport has held that line rather than
allow the navigation itself to be assisted, which would end the event.
